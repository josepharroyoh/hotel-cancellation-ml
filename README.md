\# Hotel Booking Cancellation Prediction



Projeto de Machine Learning para previsão de cancelamento de reservas hoteleiras.



O projeto será desenvolvido seguindo a metodologia CRISP-DM.



\## Objetivo



Desenvolver um modelo capaz de estimar o risco de cancelamento de uma reserva com base nas informações disponíveis da reserva.



\## Dataset



Hotel Booking Demand Dataset.



\## Status



Projeto em desenvolvimento.
