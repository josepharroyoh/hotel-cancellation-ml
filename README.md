# Hotel Booking Cancellation Prediction

Projeto de Machine Learning para previsão de cancelamento de reservas hoteleiras, desenvolvido seguindo a metodologia CRISP-DM.

## Objetivo

Desenvolver um modelo capaz de estimar o risco de cancelamento de uma reserva com base nas informações disponíveis no momento da reserva.

## Dataset

**Hotel Booking Demand Dataset**

O conjunto de dados contém informações históricas de reservas de um *City Hotel* e um *Resort Hotel*, incluindo reservas canceladas e não canceladas.

- Registros: 119.390
- Variável alvo: `is_canceled`
- Tipo de problema: Classificação binária

## Metodologia

O projeto será desenvolvido seguindo as etapas do CRISP-DM:

1. Business Understanding
2. Data Understanding
3. Data Preparation
4. Modeling
